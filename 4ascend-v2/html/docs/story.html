剧本语法说明
[角色|表情] 台词 对话框：角色名取自「角色管理」，表情名取自该角色的表情；省略表情则使用代表图，如 [导员ZERO] 你好。新增台词会自动沿用上一次的角色/表情，首次使用取角色列表第一个并选中代表图。
台词支持 <玩家名称> 占位符。
JQBJ 语言模式（编辑区上方切换）支持完整 JQBJ v0.3 语法，可直接写在大文本框里；切回拖动框模式后，条件 / 循环 / 变量等高级语句会以只读代码行保留，仍可在 JQBJ 模式中修改。
说 [角色|表情] 台词 / 菜单 ... 结束菜单 / 选项 文字 / 标签 / 跳转
设 变量 = 值 / 赋值 变量 += 数字 / 如果 变量 >= 值 ... 结束如果
重复 N 次 ... 结束重复 / 当 条件 ... 结束当 / 直到 条件 ... 结束直到 / 跳出 / 继续
对局 标题 ... 结束对局，块内可用 如果胜利 / 如果失败 / 如果平局 编写结果分支；台词中的 ${变量名} 会在播放时替换为变量值。
框 标题 色=#6f42c1 分组框开始，结束框 关闭：把成段命令收进同一个彩色框，可嵌套、颜色可自定义；分组框只用于编辑器编排，播放时自动跳过。
行首缩进 2 空格 = 1 级（Tab 按 2 空格计），可在每行左侧的 ⇤ / ⇥ 按钮调整；拖动框模式下缩进只影响排版，JQBJ 语言模式下缩进同时决定块结构（菜单 / 条件 / 循环 / 对局）。
? [角色|表情] 提示 选择节点，紧跟若干 - 选项 -> 标签；角色与表情可选（写法则同台词），留空时对话框显示「请选择」。
:标签 标签定义；-> 标签 跳转；结束 或 剧终 收尾。
* 对局 标题 对局块开始：其后的配置、代码与对话都归入该对局，直到 结束此对局 为止（编辑器会把整块包进同一个蓝色圆角对局框）。
残局码=... 初始盘面：粘贴残局页导出的残局码，棋盘将以该局面开局（同时继承其血量/回合数；可选，空则空盘 6/6 血）。残局码内若含作者定义的「引导落子点」，进入该对局后按序以红圈提示玩家落点。
结束对局=胜负|步数:12 结束对局条件：胜负 表示分出胜负即结束（默认）；步数:12 表示进入本对局后第 12 手落子即结束，结果按平局处理（跳“平局”标签，未配置则继续往下）。（旧剧本的 结束残局=... 仍兼容。）
结束后=结果|继续 对局结束表现：结果（默认）显示胜利/失败/平局；继续 不显示胜负，改为显示「继续」并直接进入下一段剧情（不跳胜利/失败/平局标签）。常与 结束对局=步数:12 搭配，用打满步数来收束剧情战斗。
结束此对局 对局块结束标记：与上一个 * 对局 之间的所有行同属一个对局框，本身不参与播放（运行时直接跳过）。
步数对话=3:标签A|落子5,5:标签B|拿起:标签C|AI拿起:标签D 对话触发条件：多条用 | 分隔，支持四类触发——第 N 手落子（如 3:标签）、棋盘指定位置落子（落子5,5:标签）、我方拿起棋子（拿起:标签）、AI 拿起棋子（AI拿起:标签）。触发后暂停本局并跳转到该标签播放对话。
刷草计划=3:5,5;6,5|9:3,3 定时刷草：回合:坐标;坐标 表示“在第几回合、于哪些点刷几株草”，多条用 | 分隔；回合数即界面 Turns，坐标为 横,竖（1-9，左下原点，5,5 为正中心）。被占用或已是二草的点会自动跳过。
我方=黑|白 玩家执子；先手=黑|白；胜利/失败/平局=标签 对局结果跳转。
继续对局 用于“步数对话”所跳转的对话末尾，表示回到当前对局继续下棋。
@ 箭头 锚点 红色动态箭头，指向界面区域；@ 圈 5,5 红色旋转虚线圈，指向棋盘交叉点（坐标 1-9，先横后竖，5,5 为正中心）；@ 清除 清除当前标注。
对话框不透明度=60 设置整篇剧情的对话框背景不透明度（0-100，单位 %，默认 60）；写在任意位置均可，播放时自动跳过。
箭头锚点：名字 / 棋子颜色 / 生命值 / 信息 / 刷草点 / 棋盘 / 我方 / 对手，或直接写元素 id（如 #game_p1_card）。
可选颜色覆盖：@ 箭头 名字 色=#ff3b30（默认 #ff2d2d）。新标注会替换上一个标注。

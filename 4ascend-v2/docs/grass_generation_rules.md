# 四子棋（4ASCEND）全模式草生成规则说明

本文档将游戏中底层算法（`GameNormal::ed\_pl\_1` / `scan\_run` / `scan\_point` / `scan\_score`）整理为自然语言的规则描述，涵盖各游戏模式与对局阶段的完整机制。

\---

## 一、模式概览与总控开关

|模式|内部标识|自然草刷新（`natural\_plant`）|超载机制表现|
|-|-|-|-|
|**普通模式 (Normal)**|`mode = 'normal'` / 0|**开启**|随盘面棋子数与血量动态激活超载 / 超载 EX|
|**永夜模式 (Night)**|`mode = 'night'` / 2|**开启**|**全局锁定处于超载 EX 阶段**（`always\_overload = true`）|
|**枯萎模式 (Blight)**|`mode = 'blight'` / 1|**关闭**|全局无草生成与刷新|
|**残局挑战模式 (Endgame)**|`natural\_plant = false`|**关闭**|沿用残局关卡预设盘面草分布，对局中不自然刷草|

\---

## 二、草生成触发时机与回合冷却机制

在启用刷草的模式（普通、永夜）下，落子与结算分为固定阶段：

1. **落子**（`ed\_tr\_1`）
2. **ASCEND 判定与升变标记**（`ed\_as\_1`）
3. **伤害与消除结算**（`ed\_as\_2`）
4. **回合轮换**（`ed\_tr\_2`）
5. **草生成阶段**（`ed\_pl\_1`）
6. **消除标记清理**（`ed\_as\_3`）

### 1\. 产生草的两个前置门槛

* **攻击回应中不刷草**：如果当前处于连打的进攻期（发起 ASCEND 后等待对手回应的阶段，即 `ascend\_status == START`），**禁止生成草**。
* **冷却计数与完整 ASCEND**：在不处于“等待回应”的回合结算阶段，草生长冷却计数器（`grow\_count`）递减 1 点。只有当以下两种情况之一发生时，才会真正触发草生成：

  1. 冷却计数减至 0（`grow\_count <= 0`）；
  2. 本次落子刚刚完成了一次**完整的 ASCEND 伤害结算**。完整 ASCEND 会直接触发一次刷草，不必等待冷却归零；但 ASCEND 的发起阶段（等待对手回应）不会刷草，也不会推进这组自然刷草计时。

### 2\. 冷却刷新公式

一旦触发生成，新的生长周期重新计算：

* **基础冷却**：初始为 11 回合。每经过 22 回合，冷却缩短 2 回合，但**最低不少于 7 回合**：
$$\\text{基础冷却} = \\max\\left(7, 11 - 2 \\times \\lfloor \\text{总回合} / 22 \\rfloor\\right)$$
* **超载缩减**：若进入超载状态，基础冷却**直接减半（砍掉 50%）**。
* **轮换奇数校验**：若折半后的冷却为偶数，则再扣除 1 回合，**强制保证冷却回合数为奇数**，确保草的刷新轮流在黑方和白方落子后呈现。

## 三、超载（Overload）状态机制

随着棋盘被填满或战局拉长，系统提供两级超载机制来打破僵局：

1. **普通模式下的超载判定**：

   * **超载准备（ENABLE）**：棋盘棋子数达到 **44 颗** 时触发。
   * **超载执行（EXECUTE / 超载 EX）**：在进入准备态后，如果**落子方的当前血量小于等于对手**，正式升级为超载 EX。
   * **超载解除**：若因一次大规模 ASCEND 提子使得盘上棋子降至 **22 颗以下**，自动解除全部超载状态。
2. **永夜模式（Night）**：

   * 跳过一切棋子数与血量判定，**从开局到终局恒定为超载 EX**，无法被解除。

## 四、单次草生成数量

* **基础生成数量**：

  * 前 64 回合：每次刷新 **2 颗** 草。
  * 第 65 回合及以后（残局阶段）：每次刷新 **3 颗** 草。
* **超载 EX 奖励**：

  * 若当前处于超载执行阶段（`EXECUTE`），生成数量额外 **+1 颗**。
* **名额上限截断**：

  * 单次生成的总草数在结算时最高不超过 **6 颗**（受合法空位限制，若有效点位不足则按实际点位数量截断）。

## 五、候选位置筛选（扫描机制）

草不会随机出现在完全空旷的区域，必须依托现有棋子生成：

### 1\. 寻找“生长源”

* **普通阶段**：以棋盘上所有已落子的实心棋子（非本次刚被消除的空位）作为源头。
* **打后结算（ASCEND）阶段**：以本次参与消除的棋子格作为优先源头。
* **冷却保护限制**：玩家在完成打后有独立的抗频繁刷草保护（`unascend\_chargef`）。当某方保护期为 0 时，其刚被消除的点位被纳入源头范围。

### 2\. 蔓延目标范围

* 从每一个符合条件的“生长源”开始，向其**米字形（上、下、左、右、左上、左下、右上、右下）8 个相邻格**辐射。若处于完整 ASCEND 触发，则源点本身也一并计入。
* **可生长格子限制**：

  * 必须是**空位**或**已被拿起的消除格**；
  * 该格**不能已经是 2 级双草**；
  * **在非超载 EX 阶段，已经拥有 1 级草的格子不能重复长草**（即普通与准备阶段只能产生 1 级单草；**只有在超载 EX 阶段，已有一级草的格子才允许升级为二级草**）。

## 六、点位智能评分与竞争权重

当符合生长条件的候选位置多于刷新配额时，系统为每一个候选点评估权重分（基础分为 500 分），由大到小排序后取前 N 名：

1. **防自杀与反打惩罚（四连检查）**：

   * 如果该空位落子能直接形成 4 连或以上（是杀招点）：

     * 默认会施加 **-450 分** 的巨大惩罚，避免系统无脑将草“喂”给即将斩杀的致命点。
     * **超载 EX 逆转**：若进入超载 EX，且该四连点仅属于劣势一方（而非双方共用的杀点），系统将给予 **+450 分** 补偿与 **+100 分** 无草奖励，主动为翻盘创造带草绝杀契机。
2. **阵型价值倾斜**：

   * 优先考察该点在己方与对方连子长度、总连接度上的差异；
   * 在普通阶段，如果某一方正处于防守弱势，系统会对落子连子较长的一方施加额外分数补偿（最高按连线差值乘倍数计算）。
3. **消除旧址偏好**：

   * 在刚发生 ASCEND 的回合，本次被消除的旧棋子原点具有 **+50 分** 额外吸引力，草有很大概率直接在战火中心重新生根。
4. **拥挤惩罚**：

   * 如果该格原本已经有一级草，在尝试堆叠二级草时扣除 **30 分** 优先级。
5. **微量随机扰动**：

   * 使用独立确定性随机算法附加微小的随机浮动分（0 到 19 分），确保同等价值的对称点位不会死板固定。
6. **二级双草锁定规则**：

   * 排序选出名额后，若同一位置在当次刷新中被重复选中，且原先已经有一级草，该格会升为二级草并锁闭，不再重复消耗名额。

## 七、草在对局中的收益结算

1. **力量提升**：

   * 无草棋子：基础子力为 **1**。
   * 1 级草（单草）：棋子子力为 **1 + 1 = 2**。
   * 2 级草（双草）：棋子子力为 **1 + 2 = 3**。
2. **对消与伤害**：

   * 当形成 ASCEND 时，双方棋子的草力量合并参与一对一的降序抵消。
   * **草的力量仅用于抵消对手的棋子与草力量，草本身不造成直接扣血伤害**（造成的扣血点数严格等于最终对消后我方**剩余的棋子枚数**）。
   * 棋子被拿走时，该格附带的草被一次性消耗并重置为无草状态。
